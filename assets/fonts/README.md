# Social preview fonts

These unmodified, static TrueType fonts are used by the server-rendered
social preview. They are kept outside `public` and do not add a client-side
font request or change the website's existing font setup.

- `InstrumentSans-Medium.ttf`: Instrument Sans, normal, weight 500.
  [Google Fonts asset](https://fonts.gstatic.com/s/instrumentsans/v4/pximypc9vsFDm051Uf6KVwgkfoSxQ0GsQv8ToedPibnr-yp2JGEJOH9npST3-Tfykyk.ttf)
  · [Upstream license](https://github.com/google/fonts/blob/main/ofl/instrumentsans/OFL.txt)
  · Local license: `OFL-InstrumentSans.txt`.
- `IBMPlexMono-Regular.ttf`: IBM Plex Mono, normal, weight 400.
  [Google Fonts asset](https://fonts.gstatic.com/s/ibmplexmono/v20/-F63fjptAgt5VM-kVkqdyU8n1i8q0g.ttf)
  · [Upstream license](https://github.com/google/fonts/blob/main/ofl/ibmplexmono/OFL.txt)
  · Local license: `OFL-IBMPlexMono.txt`.

Downloaded from the official Google Fonts CSS API on 2026-11-10:
`https://fonts.googleapis.com/css?family=Instrument+Sans:500%7CIBM+Plex+Mono:400`.
